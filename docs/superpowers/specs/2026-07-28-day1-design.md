# Day 1 Design

## Scope

Build the initial AI Agent Platform backend described in `AI-Agent-Platform-Redis-Learning.md`:
an async FastAPI service, PostgreSQL and Redis connection layers, Docker Compose
infrastructure, and readiness checks that verify both dependencies.

## Decisions

- Use SQLAlchemy 2.0 async with `asyncpg` for PostgreSQL.
- Use `redis.asyncio` for Redis.
- Expose `GET /health` for liveness and `GET /health/ready` for dependency readiness.
- Return HTTP 503 from readiness when PostgreSQL or Redis cannot be reached.
- Keep credentials and URLs in environment variables, with safe local defaults.

## Verification

Install with `uv sync`, start dependencies with `docker compose up -d`, then run
the FastAPI app and verify both health endpoints. Unit tests cover the health
responses without requiring external services.
